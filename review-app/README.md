# Замечания к чертежам

Локальный интерфейс, без внешних сервисов и отправки файлов в интернет.

Запуск из PowerShell:

```powershell
& C:\dev\buildings\scripts\start_review.ps1
```

Интерфейс: http://127.0.0.1:8765. Запуск использует Python среды Codex либо обычный `python`. Если зависимостей нет, установите `requirements.txt` тем же Python.

## Работа

1. Выберите объект и DXF.
2. Нажмите быстрое действие: **Переместить**, **Удалить**, **Добавить**, **Выровнять**, **Изменить размер**, **Исправить стык**.
3. Обведите участок, поставьте точку или протяните стрелку. Для перемещения: начало стрелки — откуда, конец — куда.
4. Добавьте пояснение и при необходимости размер. Кнопка «Готово» закрывает редактор; всё ещё можно продолжать разметку.
5. Нажмите **Сохранить замечания**. После этого напишите в чате: **«Исправь замечания»**, при нескольких объектах укажите объект.

Все быстрые действия создают замечания; сами DXF они не меняют. Перенос листа — пробел + перетаскивание, масштаб — колесо. Ctrl+S сохраняет замечания, Ctrl+Z отменяет действие, Delete убирает выбранную отметку. При вводе текста обычные клавиши работают как обычно.

Черновик сохраняется в браузере с привязкой к конкретному SHA256 чертежа. До нажатия «Сохранить замечания» агент не получает этот черновик. Последние сохранённые замечания можно открыть в другом браузере на этом компьютере: они читаются из папки объекта.

## Файлы

```text
objects/<объект>/review/
  previews/<sha256>/                  # предпросмотр из текущего DXF и преобразование координат
  revision-YYYYMMDD-HHMMSS-xxxxxx/
    source.dxf                       # снимок исходной версии
    source.svg
    comments.json                    # типы правок, текст, координаты SVG и CAD, статусы
    comments.md                      # читаемый список
    marked-preview.svg
    marked-preview.png
  latest-<sha256>.json                # указатель на последний сохранённый набор
```

Каждое сохранение создаёт отдельную ревизию. Замечания не переносятся автоматически на изменившийся DXF. Если файл изменился во время разметки, сервер просит открыть его заново. Источники не перезаписываются.

Для агента: найдите последний набор в `review/`, прочитайте `comments.json` и PNG, сопоставьте SHA256 и `source_path`. Точки содержат координаты CAD, вычисленные обратным преобразованием фактического SVG-экспорта. Не применяйте координаты к другой версии без повторного сопоставления. Стрелки показывают направление, но масштаб переноса уточняйте по указанному размеру/тексту, если пользователь их задал. Условные предположения чертежа остаются предположениями.

Сервер слушает только `127.0.0.1`; это приложение для локальной работы, не для публикации в сети. Журналы запуска находятся в `review-app/logs/`.

## Версии чертежей и просмотр источников

У каждого объекта выпуски хранятся в `output/v1/`, `output/v2/` и далее. Объектный скрипт создаёт следующую свободную версию и не перезаписывает предыдущую. В интерфейсе сначала выберите объект, затем версию и нужный DXF. Раздел «Исходные материалы» показывает сканы и изображения из `sources/` и `references/`; при просмотре исходника разметка временно выключена, замечания по-прежнему сохраняются для выбранного DXF.

Включите кнопку **«Сравнить: исходник сверху»** над быстрыми действиями, чтобы видеть скан и DXF одновременно. Масштаб и перемещение у панелей независимы; для каждой есть кнопка «Вписать». Замечания ставятся только на нижнем чертеже.


Объекты и исходные данные добавляются через чат. Интерфейс показывает сохранённые чертежи и исходники.

## Быстрая разметка и сравнение

Отметьте место на чертеже стрелкой, областью или другим инструментом. Рядом с отметкой выберите тип элемента и действие, при желании добавьте комментарий. Список замечаний нумеруется; нажатие на карточку приближает отметку. Панели объектов и замечаний сворачиваются кнопками в верхней строке.

В режиме сравнения верхнее окно показывает выбранный исходник или другой чертёж и версию; нижнее показывает чертёж для замечаний. Границу окон можно перетащить. Масштаб и перемещение каждого окна независимы. После сохранения можно скопировать запрос в чат; он содержит объект, версию, имя файла и идентификатор сохранённой ревизии.

Результаты исправлений показываются только при наличии отчёта `review-results*.json` в папке новой версии и совпадении SHA256 исходного и нового чертежей с данными исходной ревизии. Отчёт включает `source_revision`, `source_drawing`, `source_sha256`, `target_drawing`, `target_sha256` и массив `results` с `annotation_id`, `status` (`resolved`, `needs_clarification`, `not_done`) и `description`. Историческая ревизия не изменяется; при отсутствии отчёта статус не выводится.

Замечания можно удалять кнопкой × в карточке, выбирать флажками для массового удаления или удалить все сразу. Перед каждым удалением интерфейс запрашивает подтверждение; отказ не меняет список. До сохранения действие отменяется кнопкой ↶. Чтобы очистить даже последний сохранённый комментарий, сохраните пустой список: он будет записан как новая ревизия, старые ревизии остаются в папке объекта.
